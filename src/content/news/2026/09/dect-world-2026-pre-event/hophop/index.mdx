### hophop (Silano Systems)<OpenerBadge />

[hophop](https://github.com/ariel-os/hophop/) shows its example applications that run DECT NR+ firmware on [Ariel OS](https://ariel-os.org/).
Its examples show IP connectivity based on DECT NR+ between standalone embedded devices and connected PCs.
Visitors can exchange network traffic between connected PCs,
and access embedded devices' applications and DECT configuration both from the PCs and over the DECT network.
Beyond the existing applications, they can extend those applications, and watch the network traffic in Wireshark through hophop's provided sniffer application.

> In projects of the last decade, I have built Free Software towards an Internet of Things where interoperability can be expected, the user is in control, and which is secure by default.
>
> With hophop making DECT NR+ available, embedded developers can access state of the art radio technology with a good balance of range, latency and throughput while remaining in control of their network.
